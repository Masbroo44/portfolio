Algora

Algora est une plateforme web orientée trading que je développe en Vanilla HTML, CSS, JavaScript et PHP. Elle permet de gérer des comptes utilisateurs, d’enregistrer des trades, de suivre ses performances et d’analyser ses décisions. Ce projet a été conçu pour la structure Algora Finance, dont je suis membre actif.

Totally Spies

Totally Spies – Mission Bolivie est un jeu textuel développé en C, jouable dans le terminal. Le joueur suit les trois espionnes dans une infiltration d’une tour appartenant à un cartel bolivien. Chaque étage propose des affrontements, des choix narratifs, et des énigmes critiques menant au boss final. Le projet repose sur des concepts fondamentaux du langage C : utilisation de structures pour gérer les personnages, pointeurs pour manipuler dynamiquement les données, et fonctions pour gérer les actions et les transitions d’étages. L’interactivité est entièrement basée sur les entrées clavier et l'affichage texte, pour une immersion maximale dans un univers revisité de manière mature et stratégique.

POO-kemon

POO-KEMON est un mini-jeu Java inspiré de l’univers Pokémon, réalisé avec une approche orientée objet. Le joueur crée deux dresseurs et leurs Pokémon (Feu ou Eau), puis simule un combat en utilisant les principes de l'héritage, du polymorphisme et de la composition. Chaque type de Pokémon a un comportement d’attaque spécifique. Le projet met en œuvre les notions clés comme this, super et la manipulation d’objets dans un combat interactif.

SmartBike

SmartBike est un site e-commerce réalisé dans le cadre d’un projet web à l’école. Il présente des vélos électriques avec un design responsive en HTML, CSS et JavaScript, et intègre un système de paiement sécurisé via l’API Stripe. Le site combine vitrine produit, animations et fonctionnalités dynamiques pour une expérience utilisateur fluide.
